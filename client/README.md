# Todo App

A full-featured Todo application built with React, Vite, and Tailwind CSS.

## Features

- **Authentication** — Register and Login with validation, duplicate email check, and persistent sessions via localStorage
- **Todo Management** — Add todos with name, description, priority, privacy, and schedule
- **Dashboard** — View, filter, mark as done, and delete todos
- **Filters** — Filter by status, priority, privacy, and schedule simultaneously
- **Persistent Data** — All users and todos saved to localStorage
- **Toast Notifications** — Real-time feedback on all actions

## Tech Stack

- React 19
- React Router
- Tailwind CSS
- React Toastify
- Vite
